## Cài đặt

### Claude (web, ứng dụng)

1. Tải tệp zip ở trên. Không cần giải nén.
2. Vào Cài đặt, tìm mục Skills, chọn tải skill lên rồi chọn tệp zip vừa tải.

Tên mục có thể khác chút tuỳ phiên bản Claude.

### Claude Code

Giải nén tệp zip, chép thư mục `ngoi-choi-xoi-app` vào `~/.claude/skills/`, rồi mở một phiên Claude Code mới.

### ChatGPT, Gemini

Mở tệp [ngoi-choi-xoi-app/SKILL.md](ngoi-choi-xoi-app/SKILL.md), chép toàn bộ nội dung, dán vào phần hướng dẫn của một Project (ChatGPT) hoặc một Gem (Gemini).

## Dùng thế nào

Cứ nhờ AI như bình thường, ví dụ: "Làm cho tôi trang đặt lịch cho tiệm tóc, khách chọn ngày, giờ, dịch vụ rồi bấm Đặt lịch." Skill tự áp dụng khi bạn nhờ làm, sửa hoặc đưa lên mạng một webapp.
